# MyStay 🏡

MyStay is an Airbnb-inspired full-stack web application where users can explore property listings, create their own listings, and share reviews.

## Features

- **User Authentication:** Signup and login functionality.
- **Listings Management:** Create, view, edit, and delete property listings.
- **Image Uploads:** Upload and store listing images using Cloudinary.
- **Reviews & Ratings:** Share experiences through reviews and ratings.
- **Authorization:** Allow only authorized users to manage listings and reviews.
- **Validation:** Validate user input using Joi.
- **Responsive Design:** User-friendly interface built with Bootstrap.

## Tech Stack

- **Frontend:** HTML, CSS, Bootstrap, EJS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB, Mongoose
- **Authentication:** Passport.js
- **Image Uploads:** Multer, Cloudinary
- **Validation:** Joi

## Purpose

This project was built for practice and learning full-stack web development.
